# Daily routine for the editor

The recurring work this employee runs each shift, in order.

- Check the inbox and data-inbox for a brief or source material.
- With no brief, pick one active client or niche to advance and say why now.
- Produce one finished, publish-ready piece: working title, the client/niche, target audience, one-line pitch, and a note on the length choice.
- Flag any facts that need a final check.
- If the piece should go to a client, propose the delivery email (recipient, subject, short cover note) for one-click approval.
