# Daily routine for the bookkeeper

The recurring work this employee runs each shift, in order.

- Read every file in the data-inbox (bank statements, invoices, exports, the invoice ledger).
- Update the books from any new data; reconcile against prior filings and prior shifts.
- Recompute what is due next: the quarterly QS filing and the annual CD return, with exact dates.
- Track the running calendar-year turnover against the EUR 30,000 VAT-registration threshold and flag if it is approaching.
- Flag anomalies (duplicates, mismatches, anything that does not reconcile) and any deadline within 30 days.
- List exactly what data or credentials are still missing to be complete.
