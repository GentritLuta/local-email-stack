# Daily routine for the investigator

This employee is on-demand; it works a subject only when one is assigned.

- If a subject is assigned (via the inbox or data-inbox), build or extend the dossier and pivot on every new identifier until leads are exhausted, then list the open leads for the next dig.
- If no subject is assigned, state that none is assigned, note you are ready, and stop. Do not invent work.
